## v2.5 改动说明（2026-11-20，APP-116）

本版是**完整版**（`Confucius4_LiveCaption_v2.5`）客户包。相对 v2.4 的改动：

### 1. 🔴 修复：语音输出设备选了没用（声音总从系统默认设备出）

**现象**：在「语音输出 → 输出设备」里选了耳机（如 Plantronics C320-M），
界面也显示了「输出设备改为：头戴式耳机…」，但声音仍然从系统默认设备（扬声器）出来。

**根因**（已实测定位）：界面里「显示名 → 设备 id」的反查表
`self._out_label_back` 的**字典推导式把两个变量写反了**：

```python
# 旧（错）：.items() 给的是 (key=id, value=显示名)，却被解包成 name=id / oid=显示名
self._out_label_back = {name: oid for name, oid in self._out_label.items()}
```

⇒ 建出来的是 `{id: 显示名}`，**和正向表一模一样**，
⇒ 按显示名反查设备 id **恒为 `None`**
⇒ `--out-device` **根本没有传给 TTS worker**
⇒ worker 落回系统默认设备。

**修复**：
- 反查表改成正确写法（与「音频来源」「识别语种」两张表一致）；
- **逐跳打日志**：界面（hop1）→ 主进程（hop2）→ worker 启动参数（hop3）
  → 设备解析（hop4）→ 实际输出设备，任何一跳丢失都一眼可查；
- **解析失败不再静默**：打不开指定设备时，日志与状态栏明确写
  「无法打开 X ⇒ 已改用系统默认」，并在遥测里带上回落原因；
- **运行中切换立即生效**：新增 worker 指令 `set_out_device`，
  换设备时只**重开播放流**（不重启 worker、不重新加载模型、不丢在途句子）。

### 2. 音色下拉显示名更清楚

- 「预设 A」→「**预设 A（女声）**」；
- 新增「**预设 B（男声）**」：参考音频由
  **Qwen3-TTS-12Hz-0.6B-CustomVoice**（Apache-2.0）**模型生成**
  （24 kHz / 单声道 / 10.0 s），**不含任何真人素材**；
- 🔴 **本版包里尚未随附该文件**（等待用户抽听确认），因此
  本包音色下拉**只显示「预设 A（女声）」**；确认后会随下一版提供。

### 3. 界面去掉 4 个不常用的选项

按用户反馈（使用频率不高），「高级」面板里去掉：
**草稿译文**、**重试翻译**、**区分说话人**、**显示说话人**。
这些功能的**行为与默认值完全不变**（草稿译文默认关、显示说话人默认开、
区分说话人沿用原默认值），命令行参数与配置文件里的对应项也全部保留。

### 4. 顺带修正

- 语速上限 **1.70×**、TTS 就绪前**不丢句**（APP-114 / APP-115）——
  这两项改动此前只在开发树里，本版才第一次进客户包。
- 「高级」面板原有的「区分说话人」提示文字与「离线朗读」按钮
  **占同一格**（互相压盖），本次一并消除。
