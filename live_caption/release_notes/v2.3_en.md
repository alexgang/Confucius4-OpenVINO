Per the user's decision, this release ships preset voices only; voice cloning is moved out of the delivery scope into a later version.

- **Preset A is the only voice**: the "follow speaker (cloning)" option is removed from the UI (no disabled entries left behind). Speaker diarization is now labelled as caption annotation. At runtime, clone registration, speaker-encoder clone calls, and diarization-triggered voice switches never execute.
- **Old settings remain compatible**: legacy `follow_speaker` values in the command line or user settings fall back to preset A at startup with a log line, without raising an error.
- **Tighter package contents**: `ext/bridge_token.txt` is no longer shipped (generated randomly on first launch), the eight babelvox demo voices (cindy/lou/phil/steve json+npy) are excluded, and no clone voices or test wavs are included. A bundled gate scans six categories of forbidden paths after the package is built.
- **Diarization retained for captions only**: used for S1/S2 labels in subtitles. The five ASR spk modules and the 5-second static segmentation IR ship with the package; `min_clean_ratio` follows ASR-050 and defaults to 0.6.
- APP-063/065 UI fixes are merged; no cloning wording remains in the UI or status bar.

Clone fixes (APP-071/075/079) are unrelated to v2.3; that code stays on the development branch for a later release.
