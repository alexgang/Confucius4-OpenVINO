## What's new in v2.5 (2026-11-20, APP-116)

This is the **full edition** customer package (`Confucius4_LiveCaption_v2.5`).
Changes relative to v2.4:

### 1. Fixed: the voice output device selection had no effect

**Symptom**: selecting a headset in "语音输出 → 输出设备" showed up in the UI
("输出设备改为：头戴式耳机…") but the audio still came out of the system
default device.

**Root cause** (measured and confirmed): the reverse lookup table
`self._out_label_back` was built with a dict comprehension whose two variables
were swapped:

```python
# WRONG: .items() yields (key=id, value=label), but it was unpacked as name=id / oid=label
self._out_label_back = {name: oid for name, oid in self._out_label.items()}
```

⇒ it produced `{id: label}` — identical to the forward table —
⇒ looking up a device id by its display label **always returned `None`**
⇒ `--out-device` was **never passed to the TTS worker**
⇒ the worker fell back to the system default device.

**Fix**:
- correct comprehension (same shape as the "audio source" and "recognition
  language" tables);
- **per-hop logging**: GUI (hop1) → main process (hop2) → worker argv (hop3)
  → device resolution (hop4) → actual output device, so a lost value at any
  hop is immediately visible;
- **no silent fallback**: when the requested device cannot be opened, the log
  and the status bar explicitly say "无法打开 X ⇒ 已改用系统默认", and the
  telemetry carries the fallback reason;
- **switching takes effect immediately**: a new worker command `set_out_device`
  only **reopens the play stream** (no worker restart, no model reload, no
  in-flight sentences lost).

### 2. Clearer voice label in the dropdown

- "预设 A" → "**预设 A（女声）**" (Preset A, female);
- new "**预设 B（男声）**" (Preset B, male): the reference audio is
  **model-generated** by `Qwen3-TTS-12Hz-0.6B-CustomVoice` (Apache-2.0)
  (24 kHz / mono / 10.0 s), containing **no real-human material**;
- 🔴 the asset is **not yet shipped in this build** (pending user listening
  confirmation), so the voice dropdown in this package shows only
  "预设 A（女声）". It will be provided in the next build once confirmed.

### 3. Four rarely-used options removed from the UI

Per user feedback, the "高级" panel no longer shows:
**草稿译文** (draft translation), **重试翻译** (retry translation),
**区分说话人** (distinguish speakers), **显示说话人** (show speakers).
Their behaviour and defaults are unchanged, and the corresponding command-line
arguments and configuration keys are all preserved.

### 4. Incidental corrections

- Speed cap **1.70×** and **no dropped sentences** before TTS is ready
  (APP-114 / APP-115) — these changes previously existed only in the
  development tree; this is the first customer package to contain them.
- The "区分说话人" hint label and the "离线朗读" button in the advanced panel
  occupied the same grid cell (overlapping); that overlap is now gone.
