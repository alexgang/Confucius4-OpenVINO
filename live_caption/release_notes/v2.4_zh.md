# v2.4 改动说明

- **克隆音色（跟随说话人）修复**：同一说话人标签下先后出现两个人时，音色会升级到更长、更可靠的那段语音；同一段语音增长不再反复重登记。克隆音色只在内存中，不落盘。
- **说话人区分改进（默认开启）**：新的增量聚类只用"单一说话人"的片段更新声纹，不再因换人片段把两人合并成同一标签。如需旧行为，设置环境变量 `ASR_SPK_CLUSTER=v1`。
- **首次启动 TTS 的 NPU 编译时间缩短**：去掉从未使用的声码器形状（只编译 8/16/32/33 帧，512 帧改为用到时再编译）。
- **全部程序模块与开发版对齐**（修复 v2.3 中部分模块版本不一致导致的 `spk_conf` 报错）。
- v2.3 作废，不再交付。
