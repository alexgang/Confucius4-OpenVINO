# v2.4 changes

- **Clone voice (follow speaker) fix**: when one speaker label covers two people in turn, the voice now upgrades to the longer, more reliable stretch of speech; a run that keeps growing is no longer re-registered every sentence. Clone voices stay in memory only.
- **Better speaker separation (on by default)**: the new incremental clustering only updates a voiceprint from single-speaker segments, so a segment spanning a speaker change no longer merges two people into one label. Set `ASR_SPK_CLUSTER=v1` for the old behaviour.
- **Shorter first-start TTS NPU compile**: vocoder shapes that were never used are no longer compiled (only 8/16/32/33 frames; the 512-frame one compiles on first use, if ever).
- **All app modules aligned with dev** (fixes the `spk_conf` errors caused by mixed module versions in v2.3).
- v2.3 is withdrawn.
