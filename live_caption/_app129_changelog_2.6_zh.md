## v2.6 改动说明

**完整版 v2.6**（MiniMVP / SpecialMVP 不带此包）。

### 1. 保留背景音（bgkeep）进完整版

- 插件端「保留背景音」**默认开**（含从 v0.4.18 升级的老用户；手动关过的保持关）。
- **默认分离设备 = GPU.0（FP32）**；可用环境变量 `EXT_BG_DEVICE=CPU` 改；
  GPU 编译失败会自动退回 CPU。
- Demucs 分离模型**随包分发**：`models/bgsep/htdemucs_core.xml` / `.bin`
  （身份与 SHA256 见 `ACCEPTED.json` 的 `model_manifest`）。
- 分离模型缺失时**自动降级**：弹窗显示「不可用：背景分离模型缺失…」，
  配音照常（退回原声压低），模型恢复后自动恢复。

### 2. EXT 升级到 v0.4.20（4740b06）

- **克隆音色跟随男女切换**：克隆模式下无标签句按**本句声纹**找最像的已登记音色；
  **音高性别守门**（男 ≤155 Hz、女 ≥190 Hz）把明显错性别的音色换成**同性别**最像的
  （同性别没有 ⇒ 用本句自克隆）。
- 有余量（>9 s）时最多等 3 s 标签；保留背景音开时句子音频立即交给克隆管理器。

### 3. APP-123：小窗 + 直接拼接

- 声码器窗口：`chunk=8` / 左上下文 `25` 帧 / 窗口 `38` 帧；
- 拼接方式：直接拼接（`crossfade=0`）——不再逐边界丢 50 ms。

### 4. APP-130：code predictor 的 NPU 自检兜底 + 运行时保险

- 部分机型的 NPU 上 code predictor（`cp_prefill` / `cp_decode`）会输出 NaN
  ⇒ 码全乱 ⇒ talker 出不了 EOS、一句拖到帧上限（39 s 乱说）。
- **自检兜底**：搬上 NPU 后先做自检（固定种子、3 组输入、与 CPU 版逐用例比余弦）；
  不合格就**保留 CPU**，并在设备信息里如实标注。
- **运行时保险**：某步输出 NaN/Inf ⇒ **本句立刻停**并记 `tts_runaway` 计数，
  不再一直生成到帧上限。

### 5. 其它

- 包内不含 `bridge_token.txt` / `*.log` / `*.pid` / e2e 产物 / clips。
