候选替换块（精确字符串替换 + 唯一命中断言）
====================================================================
**替换 1**：把 M9 的断言本体换成「差异恰好 2 条且都是修正」的新断言。

原文（**必须逐字一致**，命中数应为 1）：

    check('MATCH', 'M9 真实语料：与「最小改动版」逐条一致',
          m == minimal(drafts, finals),
          f'shipped={len(m)} minimal={len(minimal(drafts, finals))}')

替换为：

    # 🔴🔴 **§44 更新（2026-10-26）**：M9 的原断言「产品规则 == 最小改动版」
    #   在 §44 引入「跨段上限」后**必然 FAIL** ⇒ **前提已过期**，不是产品缺陷。
    #   ⇒ 改为断言**差异恰好 2 条**，且这 2 条**必须都是跨段离群错配的修正**
    #   （§44 的修复目标）⇒ 若差异数 ≠ 2 ⇒ 说明改动越界 ⇒ 必须 FAIL。
    _m9_min = minimal(drafts, finals)
    _m9_diff = [(di, _m9_min.get(di), fi)
                for di, fi in sorted(m.items())
                if _m9_min.get(di) != fi]
    _m9_far = 0
    for _di, _mi, _fi in _m9_diff:
        _ds = drafts[_di].get('seg')
        _fs_old = finals[_mi].get('seg') if _mi is not None else None
        _fs_new = finals[_fi].get('seg')
        if (isinstance(_ds, int) and isinstance(_fs_old, int)
                and isinstance(_fs_new, int) and _fs_old - _ds > 10
                and _fs_new - _ds <= 10):
            _m9_far += 1
    check('MATCH', 'M9 真实语料：与「最小改动版」的差异**恰好 2 条**且都是跨段错配修正',
          len(_m9_diff) == 2 and _m9_far == 2,
          f'n_diff={len(_m9_diff)} n_far_fixed={_m9_far} '
          f'shipped={len(m)} minimal={len(_m9_min)}')

**替换 2**（可选，防御性）：在 M9 之前补一条「跨段上限生效」的独立断言。

    # 🔴 **§44 新增**：跨段距离上限必须真的生效（否则上面的差异数就不可能是 2）
    check('MATCH', 'M9b 真实语料：配对的跨段距离 ≤ MAX_SEG_SPAN（无离群错配）',
          all(not (isinstance(drafts[di].get('seg'), int)
                   and isinstance(finals[fi].get('seg'), int)
                   and finals[fi].get('seg') - drafts[di].get('seg') > 10)
              for di, fi in m.items()),
          'n_pairs=%d' % len(m))
