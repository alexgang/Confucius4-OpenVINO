# 实时翻译配音（EXT 插件）使用说明

> 适用版本：EXT v0.4.4 · 更新日期：2026-11-11
>
> 本插件抓取浏览器**当前标签页**的音频，交给「实时配音桥接」完成
> **语音识别 → 翻译 → 语音合成**，再按时间戳**延迟 D 秒**播放配音。
> 运算可以在本机，也可以在**同一局域网里的另一台电脑（运行端）**上。
> 音视频只在本机或局域网内传输，不上传到任何外部服务器。

## 1. 两种用法：本机 / 局域网远程

| 用法 | 桥接服务跑在哪 | 插件装在哪 | 面板里「桥接服务」填 |
|---|---|---|---|
| **本机** | 本机 | 本机 | `ws://127.0.0.1:8765/`（默认值，不用改） |
| **局域网远程** | 运行端（有 GPU/NPU、装了实时字幕 App） | 同网段任意电脑 | `ws://<运行端 IP>:8765/` |

远程用法下，识别、翻译、合成、克隆音色**全部在运行端算**，看视频的电脑只负责抓声音和播放配音，对它的硬件没有要求。

> ⚠️ **同一时间只服务一个人**（按电脑 IP 计）。有人在用时，别的电脑的面板会提示「桥接正在被另一台电脑使用」，等前一个人停止后再试。

## 2. 启动桥接服务（运算的那台电脑）

### ⚠️ 先关掉实时字幕 App

实时字幕 App 和桥接服务**抢同一块 GPU 和 NPU**，只能二选一。检测到实时字幕 App 在运行时，桥接会**拒绝启动**并提示「检测到实时字幕 App 在运行」。

### 用桌面快捷方式启动

1. 双击桌面上的 **「实时配音桥接 v0.3.9（可局域网）」**，会弹出「实时翻译配音 · 桥接服务」小窗口；
2. **要给别的电脑用**：勾上 **「允许局域网访问（同网段其它电脑可连，同一时间一个人）」**；
   只在本机用就**不要勾**（不勾时只监听本机，别的电脑连不上）；
3. 点 **「启动」**，等日志出现 `真实引擎已接线` 和 `TTS 就绪`（**首次加载要 20–40 秒**）；
4. 勾了局域网访问时，日志里还会出现「局域网模式：监听 0.0.0.0，允许网段 [...]」。

> 「允许局域网访问」要在**点启动之前**勾选。已经启动了想改，先点「停止」，勾好再「启动」。

### 局域网模式的安全边界

* 只接受**本机**和 **A 所在网段**的连接，别的网段一律拒绝；
* 只接受**本插件**发起的连接（浏览器会带上插件的身份，网页冒充不了）；
* 本机防火墙已放行本网段的 TCP **8765 / 8766** 入站；
* 传输是**不加密**的 `ws://`，只适合在公司内网使用。

> **v0.4.0 起已取消 token 配对**，不需要复制任何 token。

<details>
<summary>高级：不用快捷方式，命令行启动</summary>

```
cd <插件目录>
set EXT_BRIDGE_LAN=1
"<安装目录>\python\python.exe" -m ext.bridge --real --pipeline --target-lang zh --port 8765
```

* `set EXT_BRIDGE_LAN=1` 这一行等于勾「允许局域网访问」，只在本机用就去掉这一行；
* 允许的网段默认取本机网卡的真实网段，可用 `set EXT_LAN_ALLOW=10.188.192.0/21` 指定（逗号分隔多个）；
* 必须用实时字幕 App 自带的 Python（openvino 等库只在那里），否则会报「真实引擎接线失败」。

</details>

## 3. 安装插件（看视频的那台电脑）

### 3.1 拿到插件文件夹

插件本体是安装目录下的这个文件夹：

```
<安装目录>\extension
```

* **本机用**：直接用这个文件夹；
* **别的电脑用**：把整个 `extension` 文件夹拷过去（U 盘、共享盘都行），放在一个**以后不会删**的位置，例如 `C:\LiveDub_EXT`。

> 插件带固定身份（manifest 里的 key），所以拷到哪台电脑，扩展 ID 都是同一个
> `kekgmfkijphpfndbbpakjaokamkeooib`，桥接认得它。**不要改文件夹里的 manifest.json。**

### 3.2 在浏览器里加载

**Edge：**
1. 地址栏输入 **`edge://extensions`** 回车；
2. 打开左侧（或左下角）的 **「开发人员模式」** 开关；
3. 点 **「加载解压缩的扩展」**，选中上面那个 `extension` 文件夹（选 `extension` 这一层）。

**Chrome（116 或更高）：**
1. 地址栏输入 **`chrome://extensions`** 回车；
2. 打开右上角的 **「开发者模式」**；
3. 点 **「加载已解压的扩展程序」**，选中 `extension` 文件夹。

加载成功后会出现「实时翻译配音」卡片，版本号应为 **0.4.4**。建议点工具栏的拼图图标，把它**固定**到工具栏上。

### 3.3 插件更新后

拿到新版文件夹后覆盖旧文件夹，再到 `edge://extensions` 在插件卡片上点 **「重新加载」**（圆形箭头）。不需要删掉重装。

### 关于「开发人员模式」的提示

浏览器启动时可能提示「已停用开发人员模式扩展」或「扩展程序未在商店中列出」，这是正常提示，不影响使用。但**不要关掉「开发人员模式」开关**，关了插件会被停用。

## 4. 日常怎么用

1. **关掉 VPN**（GlobalProtect 等）——远程用法下 VPN 会把发往 A 的流量拐走，导致连不上（见第 8 节）；
2. 确认桥接服务已启动（第 2 节）；
3. 打开要配音的网页，**开始播放**视频，并让这个标签页**保持在前台**；
4. 点工具栏上的 **「实时翻译配音」** 图标，在面板里：
   * **桥接服务**：本机用保持默认；远程用填 `ws://<A 的 IP>:8765/`；
   * 选 **目标语言**、**音色** 等（见第 5 节）；
   * 点 **「开始」**；
5. **远程用法第一次点「开始」**时，浏览器会弹窗请求「访问 `<A 的 IP>` 上的数据」，点 **「允许」**（之后不再问）；
6. 配音会在**延迟 D 秒**后播出。

> 抓的是**标签页正在播放的声音**。视频标签页切到后台时，浏览器可能暂停或静音它，配音也会停。

### 「打开延迟画面播放器窗口」

勾上后会额外开一个窗口，播放**延迟 D 秒**的画面和字幕，画面与配音对齐，适合对照口型和字幕。

## 5. 各项设置怎么调

| 设置 | 含义 | 建议 |
|---|---|---|
| **桥接服务** | 桥接地址 | 本机 `ws://127.0.0.1:8765/`；远程 `ws://<A 的 IP>:8765/` |
| **延迟 D（6–20 秒）** | 配音比原声晚多少秒播出 | 默认 **20 秒**。调小跟得更紧，但更容易追不上 |
| **目标语言** | 配音译成的语言 | 10 种：中文 / English / 日本語 / 한국어 / Deutsch / Français / Español / Português / Italiano / Русский |
| **音色** | `预设 A` = 固定音色；`克隆说话人` = 模仿视频里说话人的音色 | 默认预设 A；克隆见第 6 节 |
| **原声压低量（dB）** | 原声压低多少（0 = 不压低） | **−15** 起步；想盖住原声调到 −40；两个都想听清调到 −6 |
| **字幕开关** | 是否显示字幕 | 建议开着，方便核对译文 |
| **打开延迟画面播放器窗口** | 额外开一个延迟画面窗口 | 建议开 |

* 设置**一改就保存**，下次打开面板还在；
* **会话进行中**改了目标语言或音色，要**停止后重新点「开始」**才生效；
* 原声压低量、字幕开关运行中改**立刻生效**。

### 面板上实时显示的数字

* **语速倍率**：为了追进度，这一句配音加快了多少（`1.00×` = 没加速）。按落后程度逐步加快，**最高 1.5×**，变速时尽量保持音色不变；译成中文时最低约 1.10×（中文配音通常比原声长）；
* **当前滞后**：配音落后原声多少秒，越大说明越跟不上。

## 6. 克隆说话人音色

### 怎么打开

面板 **「音色」** 下拉框选 **「克隆说话人」**，再点「开始」。**默认是「预设 A」**，不选的话一直是预设音色。

本机和远程用法都支持，远程时克隆**在运行端计算**，看视频的电脑不需要额外配置。

### 它是怎么工作的

* 桥接服务从视频原声里分辨不同的说话人，并在**换人的地方切句**；
* 新说话人的第一句：如果这句本身有 **1.5 秒以上**的语音，就直接用它取音色；太短的话先用预设 A；
* 这个说话人攒够约 **3 秒**干净语音后，给他定下一个**固定的参考音色**，之后一直用这个，不会越变越不像；
* 每个说话人各用各的音色。

### 注意

* 必须是**真实引擎**模式（桌面快捷方式启动的就是）；测试用的 echo 模式没有克隆；
* 效果依赖素材：背景音乐很响、多人同时说话、录音很差时，音色可能不像，也可能分错人；
* 克隆比预设 A 多占一些算力，素材很长时滞后可能更大；
* 克隆用的参考音频存在**运算那台电脑**的 `%LOCALAPPDATA%\LiveDubEXT\clone_voices\`，**每次启动会话时清空**，只在本次使用。

## 7. 怎么停止 / 退出

* **停止并收尾（推荐）**：面板点 **「停止并收尾（跑完最后一句）」**，桥接会把最后一句跑完再停；
* **立即停止**：面板点 **「停止」**，最后一句会被切掉；
* **关掉桥接服务**：在桥接小窗口点 **「停止」**，再关窗口。远程用法下，**你停止后别人才能连上**。

## 8. 常见问题与处理

| 现象 | 原因 | 怎么办 |
|---|---|---|
| **面板提示「连不上桥接服务」/「未连接」**（远程） | ① 开着 VPN；② A 上没勾「允许局域网访问」；③ 桥接没启动；④ 地址填错 | ① 断开 VPN（GlobalProtect 会接管到 A 所在网段的路由）；② A 上停止 → 勾选 → 启动；③④ 检查 A 的桥接窗口和面板里的地址 |
| **提示「桥接正在被另一台电脑使用」** | 同一时间只服务一个人 | 等对方停止；或让对方点「停止」 |
| **点「开始」后弹窗请求访问某个 IP** | 远程用法第一次连这台主机 | 点「允许」；点了拒绝会提示「未授权访问桥接主机」，再点一次「开始」重新授权 |
| **「检测到实时字幕 App 在运行，拒绝启动」** | 设备互斥 | 在运算那台电脑上关掉实时字幕 App，再点「启动」 |
| **「端口已被占用」** | 那台电脑上已有一个桥接在运行（可能是另一个快捷方式启动的） | 先在已打开的桥接窗口点「停止」并关掉，再启动；只开一个桥接 |
| **「拒绝连接：Origin 非法」** | 插件文件被改过或不是正常加载的 | 重新拷一份原版 `extension` 文件夹并重新加载；不要改 manifest.json |
| **点了开始没声音** | 视频标签页切到后台 / 视频没在播放 | 切回视频标签页并播放 |
| **弹出「选择要共享的标签页」** | 浏览器的抓取方式回退 | 选正在播放视频的标签页，**勾上「也共享标签页音频」**，点共享 |
| **DRM 网站黑屏**（Netflix 等） | 受保护内容不允许抓取 | 不支持，换普通网站 |
| **配音越来越落后** | 见第 9 节 | 已知限制，不是操作问题；可把 D 调大，或改用预设 A |
| **桥接窗口点「启动」后很久没动静** | 首次加载模型要 20–40 秒 | 耐心等；日志在 `%LOCALAPPDATA%\LiveDubEXT\bridge.log` |
| **加载完显示「引擎未就绪」** | 某个引擎加载失败 | 看窗口里红色的原因和 `bridge.log`；常见原因是实时字幕 App 在运行 |

## 9. 当前已知限制

* **长视频可能越来越落后**：识别 + 翻译 + 合成整体还没有足够的速度余量。落后时只加快配音（最多 1.5×），**视频速度始终不变**；仍追不上时配音会排队顺延，**不丢句、不静音**，但会落后画面；
* **同一时间只服务一个人**，暂不支持多人同时远程使用；
* **局域网传输不加密**（`ws://`），只在内网使用；
* 德语、法语等拉丁字母语言的视频，目标选「English」时，可能被误判为「已经是英语」而**不翻译**（直接用原文配音）；英语视频译成这些语言不受影响；
* 插件以**开发人员模式**加载，不是商店安装包。

## 10. 文件都在哪儿

| 路径 | 是什么 |
|---|---|
| `<安装目录>\extension\` | 插件本体（加载扩展时选这一层；拷给别的电脑也是拷这个） |
| `<安装目录>\ext\` | 桥接服务与推理适配层 |
| `<安装目录>\tools\ext_launcher.py` | 桥接启动器（桌面快捷方式指向它） |
| `%LOCALAPPDATA%\LiveDubEXT\bridge.log` | 桥接服务日志（排查问题先看这里） |
| `%LOCALAPPDATA%\LiveDubEXT\clone_voices\` | 克隆参考音频（每次会话开始时清空） |
