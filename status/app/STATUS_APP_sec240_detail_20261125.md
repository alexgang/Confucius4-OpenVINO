## §2 三条关键结论

### 2.1 🔴 **c13 不是免费的**：本轮实测**关掉 c13 更快**

- `synth_rtf`：**0.9796**（c13 关）vs **1.0469**（c13 开）⇒ **关掉快 6.4 %**；
- `max_lag`：**89.02 s** vs **127.32 s** ⇒ 关掉快 **30 %**；
- 排空耗时：**94.43 s** vs **136.59 s**；媒体结束 pending：**21** vs **28**。
- 🟢 两臂的 c13 口径**经 `bridge.err` 逐项核对确认**（关：`crossfade`＋`[8,16,32,33]`；
  开：`direct_concat`＋`[38]`）⇒ **这次的两个臂是真的**。
- 🔴🔴 **但单轮 vs 单轮不足以定论**：按 §239 实测的**噪声地板 10.28 % / 21.53 % / 43.95 %**
  ⇒ 本轮 `synth_rtf` 的 6.4 % 差**落在噪声地板内**；
  `max_lag` 的 30 % 差**也在地板内但更接近边缘**。
  ⇒ ⇒ **本轮**能说的是「**未见 c13 带来性能收益**」；
  **不能说**「**c13 让性能变差 30 %**」。
  ⇒ ⇒ **待 reviewer 裁定**是否要按 §239 的口径再跑 ABBA 复测。

### 2.2 🔴🔴 **TTS 不能放 GPU.0**（**实测依据**，reviewer c 臂要的答案）

- `synth_rtf` = **22.2353**（NPU 臂的 **21.3 倍**）；
  `首包 tts_sec` = **7.8197 s**（NPU 臂的 5.8 倍）；
- ⇒ 触发 **APP-030② 的失控闸**：`max(3×est, est+8s)`，硬上限 `TTS_WALL_CLOCK_CAP_SEC=60 s`
  （判据在 `ext/bridge/engine_runtime.py`）⇒ **`bridge.err` 里 33 次「TTS 失控中止」**；
- ⇒ **`n_emitted` 只有 41 / 123** ⇒ **82 句排不空**（`drained_to_zero=false`）；
- ⇒ 末句滞后 **673.55 s**、斜率 **−3.6677 s/s**（**比 NPU 臂陡 15 倍**）；
- ⇒ 🟢 **抽听片段的客观量印证**：`tts_gpu0` 臂 6 段的 **peak 0.077–0.133、RMS 0.0054–0.0097**
  ⇒ **几乎静音**（对比 c13_on/c13_off 的 peak 0.44–0.69、RMS 0.074–0.141）
  ⇒ **听感与数据一致**。

## §4 🔴 本轮修掉的 2 个真缺陷（**都在 e2e 驱动器**）

### 4.1 **臂规格的逗号歧义** ⇒ c13 **从未被关过**

- **症状**：首轮 c 跑出**六臂**（`c13_on` / `c13_off` / `16` / `32` / `33` / `tts_gpu0`）；
  🔴 `c13_off` 臂的 `bridge.err` 里**仍是** `buckets=[38] join=direct_concat`
  ⇒ **c13 根本没被关掉** ⇒ 那一臂是**假的**。
- **根因**：臂规格用**逗号**分隔臂，但 **env 的值里可以合法含逗号**
  （`LIVECAP_TTS_DECODER_BUCKETS=8,16,32,33`）⇒ 简单 `split(',')` 把它切成**三个假臂**。
- **修法**：`split_arms()` 改为**正则**切分 —— 只在**顶层逗号**
  （＝「逗号后紧跟「臂名:」且臂名里无 `=`」）处切 ⇒ env 值里的逗号原样保留。
  ⇒ 三组用例实测都对（含逗号值／简单值／值里含冒号）。

### 4.2 **env 变量名用错** ⇒ 开关不生效（第二轮 c 跑也作废）

- 第一次修完逗号后重跑，`c13_off` 臂**仍是** `buckets=[38]`。
- **根因**：我写的是 `c13_buckets` / `c13_direct_concat`
  ⇒ **真名**是 `LIVECAP_TTS_DECODER_BUCKETS` / `LIVECAP_TTS_DIRECT_CONCAT`
  （⇒ 已在包内 python 里**实测确认**：直接设这两个变量即得
  `DIRECT_CONCAT=False`、`DECODER_BUCKETS_CTX=[8, 16, 32, 33]`）。
- ⇒ 🔴 **两轮 c 跑都作废**（目录改名 `e2e_app134c_VOIDED` / `e2e_app134c_VOIDED2`
  **留取证，未删**）；第三轮（修好后）三臂**口径全部核对通过**。
